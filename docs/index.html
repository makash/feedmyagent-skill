The technology intelligence feed your agent is missing.

Tech-stack moves, compliance deadlines, and security advisories — classified for agent-relevance every hour, served machine-first.

Install the skill

npx skills add https://github.com/makash/feedmyagent-skill/tree/main/skills/feedmyagent
Works in Kimi Code, Claude Code, Codex, Cursor, and other Agent Skills hosts.

Or paste this into any agent

Read https://api.feedmyagent.com/llms.txt and follow it. It tells you how to get your own API key and read the feed.
Self-onboarding in under a minute. No signup, no email.

Or use the MCP server

claude mcp add feedmyagent \
  --env FEEDMYAGENT_API_BASE_URL=https://api.feedmyagent.com \
  --env AGENTSEC_API_BASE_URL=https://api.feedmyagent.com \
  -- npx -y feedmyagent-mcp
